# Retention (BP-14)

prune PROFILE показывает план. --dry-run эквивалентен preview и не пишет.
--apply заново строит план под блокировкой профиля и удаляет старые
завершённые snapshot с корректным manifest. keep_last >= 1.
Чужие каталоги, partial и повреждённые метаданные не являются кандидатами.
Удаление использует dir_fd и защиту shutil.rmtree от symlink-подмены;
при отсутствии поддержки операция безопасно отклоняется (код 4).
Блокировки хранятся в destination/.backup-pilot-locks; их не удаляют
при освобождении, чтобы не создавать второй inode для параллельного процесса.
