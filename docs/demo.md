# Демонстрация на 7–10 минут

Пока это сценарий будущей демонстрации, а не подтверждение готовности.

| Время | Что показать | Кто ведёт |
|---|---|---|
| 0:00–1:00 | Задача, пользователи, шесть обязательных функций и границы | Вадим |
| 1:00–2:00 | Архитектура и поток данных, безопасные пути и права | Вадим |
| 2:00–3:00 | Чистая Astra, установка `.deb`, запуск из PATH, версия | Алексей |
| 3:00–4:30 | Профиль, исключение, dry-run, backup, snapshots | Вадим |
| 4:30–6:00 | Verify, повреждение учебной копии, отказной сценарий, restore и сравнение байтов | Ника |
| 6:00–7:00 | Retention с preview, systemd timer и журнал запуска | Алексей |
| 7:00–8:00 | Тесты A1–A5, GitHub/GitFlic CI, история ревью, вклад каждого | Ника |
| 8:00–9:00 | Финальный release, ограничения, вопросы | Все трое |

Готовить только учебные данные; иметь сохранённые логи на случай сбоя показа.
Каждый участник объясняет свою часть и общий путь от профиля до восстановления.
Перед предзащитой другой участник воспроизводит всё с нуля по README, без ручной правки исходников.
