# Руководство пользователя

**Пока проект инструкции:** исполняемой программы и установочного пакета ещё нет.
Команды ниже — проектные интерфейсы из архитектуры, их проверка входит в BP-19 и BP-26.

Пользовательский путь: установить проверенный `.deb` → создать профиль по примеру → validate →
`run <profile> --dry-run` → `run <profile>` → `snapshots` → `verify` → `restore` в новый каталог.
Перед удалением старых версий выполнить `prune <profile> --dry-run`, проверить список и затем `--apply`.

В финальной версии описать точные команды установки, создания/проверки профиля, исключений,
расписания, резервного копирования, контроля целостности, retention и восстановления;
привести реальный ожидаемый вывод и действия при ошибках прав/диска/повреждения.
Не предлагать восстановление поверх оригинала. Для обычных операций не использовать sudo без необходимости.

Приёмка руководства: другой участник на новой Astra выполняет основной и отказной сценарий
только по README и этому документу. До такой проверки документ не считается готовым.
