## Порядок выполнения

Архитектура и тестовый стенд → один сквозной сценарий → обязательные функции и ошибки →
локальные тесты → первый `.deb` → воспроизводимые локальные lint/test/package → CI →
испытания на чистой Astra → релиз. Упаковка не заменяет работающее приложение.
Дополнительные функции начинаются только после обязательной приёмки.
