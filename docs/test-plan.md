## 2. Детальные сценарии тестирования (Acceptance Criteria)

### TC-A1: Исключение файлов (Glob-паттерны)
*   **Данные:** На стенде `bpuser` в `source/` есть `bin/sample.bin`, `cache/item.txt`, `notes.tmp`.
*   **Шаги:** Выполнить `backup-pilot run --profile <name>` с `exclude = ["*.tmp", "cache/**"]`. Перейти в `.../data/` снапшота.
*   **Ожидаемый результат:** Присутствует только `bin/sample.bin` (и другие разрешенные файлы). `notes.tmp` и папка `cache` отсутствуют.

### TC-A2: Политика Retention (keep_last)
*   **Данные:** Сделано 4 завершенных снапшота. В конфиге `keep_last=2`. Рядом лежит чужой каталог (другого профиля).
*   **Шаги:** Выполнить `backup-pilot prune --profile <name>` (или очередной run).
*   **Ожидаемый результат:** Осталось 2 последних снапшота. Самые старые удалены. Чужой каталог и `.partial-*` не затронуты.

### TC-A3: Режим Dry-run
*   **Данные:** Настроенный профиль, существующий source.
*   **Шаги:** Зафиксировать `sha256sum` и `mtime` файлов. Выполнить `backup-pilot run --dry-run`.
*   **Ожидаемый результат:** Exit code 0. В destination не появились папки `.partial-*` или новые снапшоты. Хэши и даты файлов не изменились.

### TC-A4: Побайтное восстановление (Integrity & Restore)
*   **Данные:** Снапшот с бинарным файлом `bin/sample.bin`. Эталонный SHA-256: `7daca2095d0438260fa849183dfc67faa459fdf4936e1bc91eec6b281b27e4c2` (из BP-02).
*   **Шаги:** Выполнить `backup-pilot restore --snapshot <ID> --to /tmp/restore_test`. Сравнить `sha256sum` оригинала и восстановленного файла.
*   **Ожидаемый результат:** Exit code 0. Хэши совпадают побайтно. Исходные файлы не перезаписаны.

### TC-A5: Обнаружение повреждения (Integrity)
*   **Данные:** Завершенный снапшот с `manifest.json` (`files: [{path, sha256}]`).
*   **Шаги:** Изменить 1 байт в файле внутри `.../data/`. Выполнить `backup-pilot verify --snapshot <ID>`.
*   **Ожидаемый результат:** Exit code 5. Вывод в stderr: "Integrity violation: hash mismatch".

### TC-ERR-01: Неверная конфигурация (Exit Code 2)
*   **Данные:** TOML-файл с `source`, содержащим `..` или symlink.
*   **Шаги:** Выполнить `backup-pilot profiles validate --config bad.toml`.
*   **Ожидаемый результат:** Exit code 2. Вывод: "Invalid config: path traversal/symlink is not allowed".

### TC-ERR-02: Отказ доступа (Exit Code 3)
*   **Данные:** Запуск от `bpuser` на файл, у которого нет прав на чтение.
*   **Шаги:** Выполнить `backup-pilot run --profile <name>`.
*   **Ожидаемый результат:** Exit code 3. Вывод: сообщение об отказе доступа.

### TC-ERR-04: Конкурентный запуск (Exit Code 6)
*   **Данные:** Запущен один процесс `run`.
*   **Шаги:** Запустить второй `run` того же профиля в другом терминале.
*   **Ожидаемый результат:** Exit code 6 (профиль занят).

## 3. Автоматические проверки (Unit / Integration)
*   **Unit:** валидация путей/keep_last, безопасное разрешение путей restore, проверка SHA-256 по манифесту (согласно BP-01).
*   **Integration:** `профиль → run → verify → restore → сравнение байтов → prune`.
*   **Отказы:** Отсутствующий источник (exit 3), запрет прав (exit 3), поврежденный manifest (exit 5), конкурентный запуск (exit 6).
