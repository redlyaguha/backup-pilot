# Финальный чек-лист

Это требования к сдаче, а не подтверждённые результаты. Продукт ещё не реализован.

- [ ] Все 6 обязательных функций доступны через единый CLI.
- [ ] A1–A5 пройдены на чистой Astra Linux SE 1.8 x86-64; сохранены фактические результаты.
- [ ] `--help`, `--version`, основная команда и status/doctor работают из PATH.
- [ ] Unit, конфигурационные, отказные и integration/smoke тесты выполняются воспроизводимо.
- [ ] `.deb` устанавливается, обновляется и удаляется; конфиги и пользовательские копии сохраняются по политике.
- [ ] systemd timer запускает валидированный профиль с минимальными правами.
- [ ] Dry-run не меняет данные; retention и restore не выходят за разрешённые границы.
- [ ] Локальные lint/test/package и CI реальны; `.deb` опубликован как artifact.
- [ ] На GitFlic есть исходники, финальные ветки/теги и зелёный `gitflic-ci.yaml`.
- [ ] README и user/admin guide позволяют всё повторить без преподавателя и исходников на ВМ.
- [ ] Архитектура, test-plan, demo и CHANGELOG соответствуют фактической версии.
- [ ] Версия в коде, Debian metadata и tag согласована; финальный release доступен.
- [ ] Нет секретов, реальных копий, IDE cache и dev venv в пакете/Git.
- [ ] Все трое имеют собственные содержательные коммиты, ревью и могут объяснить проект.
